## 🚦 SignalMeter - Trading Traffic Light System

I work on **SignalMeter**, a crypto trading analytics platform built around a simple **traffic-light logic**:

- 🟥 **Red** - high risk / no trade  
- 🟨 **Yellow** - caution / wait  
- 🟩 **Green** - possible trade opportunity  

SignalMeter helps traders make faster and more disciplined decisions using:
- technical indicators such as RSI, EMA, MACD and Bollinger Bands
- real-time market data
- clear visual trading signals
- risk-management logic
- psychology and discipline tools
